# PadelBook

## Project Overview

PadelBook is a sports booking platform designed to make playing sports easier and more accessible. It helps users discover and book sports courts, find other players to join their games, and split booking costs among participants.

## Project Objectives

* Simplify the process of finding and booking sports courts.
* Help players connect with others and form groups for games.
* Enable players to share and split booking costs.
* Provide clear information about court locations, prices, and available services.
* Help sports venue owners manage bookings and reduce scheduling conflicts.

## Project Scope

### User Features

* Search for sports courts by location, price, and available services.
* View court details and available booking slots.
* Book courts and track booking status.
* Find other players and join sports groups.
* Split booking costs among participants.

### Venue Management Features

* Manage court availability and booking schedules.
* View and organize reservations.
* Reduce double bookings and scheduling conflicts.
* Track bookings and related revenue.
